# 🎮 Video Game Sales Analysis 🚀

Analyze global video game sales data to uncover trends, top-selling platforms, and regional patterns. 📈🎮

## 📊 Overview 😎

This project performs exploratory data analysis on the [Video Game Sales](https://www.kaggle.com/gregorut/videogamesales) dataset. It covers:

1. Sales by platform, genre, and year 🎮
2. Regional breakdown (NA, EU, JP, Other) 🌍
3. Revenue forecasting via simple regression models 💹

## 🗂️ Data 📦

- **Source:** Kaggle “Video Game Sales” 🎰
- **Files:**
  - `video_games_sales.csv` – sales data 📝
  - `Video Game Sales Analysis.ipynb` – analysis notebook 📓
